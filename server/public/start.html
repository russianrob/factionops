FactionOps — Quick Start

Two minutes. Read it once. Then you'll know what to do during a war.

1Install the script

FactionOps is a Tampermonkey userscript. If you don't have Tampermonkey:

  • Desktop browsers (Chrome / Edge / Brave / Firefox): install the Tampermonkey extension from your browser's add-on store.
  • Torn PDA mobile app: open Userscripts in PDA settings — userscripts are supported natively, no extension needed.

Then click this link once and Tampermonkey will offer to install:

Install FactionOps

When Tampermonkey shows the install prompt, click Install. Updates roll out automatically — you don't need to re-install when versions change.

2First-time setup (API key)

FactionOps needs your Torn API key to read war / faction data. Limited Access tier is fine (Public usually works too — Limited just enables more features).

Torn PDA users: nothing to do — FactionOps auto-uses PDA's managed API key. You should see the overlay on faction war pages immediately.

Desktop / browser users:

  1. Open any Torn faction page (e.g. factions.php) — the FactionOps overlay should appear in the corner.
  2. Click the ⚙ gear icon in the FactionOps panel (top-right of the overlay).
  3. Paste your Torn API key into the API Key field, click Save.
  4. Refresh the page. The overlay now has your data and you're set — the key is stored locally on your device only.

Don't have a key? Get one at torn.com/preferences.php#tab=api — pick Limited Access. If the overlay doesn't appear at all, refresh once; if still missing, check Tampermonkey is enabled for torn.com in your browser's extensions menu.

Overlay quick reference
  • ⚙ gear icon — opens Settings (API key, preferences, faction key pool toggle)
  • Click the FactionOps logo / icon — closes the overlay (click again to reopen)

3Calling enemy targets Call

"Calling" a target reserves them for you so two faction members don't waste energy hitting the same enemy at the same time.

  1. On the war page, find an enemy you want to attack.
  2. Click the Call button on their row.
  3. The whole faction now sees the target tagged with your name in their FactionOps overlay. A toast notification pops up for everyone: "YourName called EnemyName."
  4. Go attack. When you're done (or you change your mind), click Call again to release them — others can now take them.

If a target already has someone else's name on it (Called by Other), don't hit them unless you've coordinated. Pick a different target.

4Deal calls — DO NOT ATTACK 🔒 Deal

Important

Sometimes leadership arranges a deal with the enemy faction — for example, holding off on a specific player so the enemy holds off on one of ours, or coordinating a hospitalization swap.

When a deal is in place, the target shows 🔒 Deal next to their name in your FactionOps overlay, and you'll see a toast: "Admin called EnemyName 🔒 Deal."

If you see the 🔒 Deal badge on a target — do NOT attack them.

Deal calls expire automatically after 15 minutes. If the badge disappears, the deal is over and the target is fair game again. If you're unsure, ask in faction chat before swinging.

5Chain bar

FactionOps shows the faction's live chain count + a "Next Up" queue at the top of the page. Watch for:

  • The chain timer dropping toward zero — if no one's hitting, jump in to keep it alive.
  • "Next Up" suggestions — a list of optimal hospital-trade or low-stat targets the script picks for you. Click one to be taken straight to the attack page.
  • Bonus drops (every 25, 50, 100, etc.) — these are usually called by leadership. Don't take a bonus hit unless leadership has assigned it to you.

6The five rules

  1. Always click Call before attacking so the faction can see you've taken the target.
  2. Click Call again to release when you're done or moving on.
  3. Don't hit targets called by others unless coordinated.
  4. Never hit a 🔒 Deal target. Period.
  5. Don't take bonus hits (25 / 50 / 100 / 250 / 500 / 1000 / 2500 / 5000 / 10000 / 25000) unless leadership assigns you.

7Push notifications (optional but recommended)

FactionOps can push you alerts even when Torn isn't open — chain breaking, vault requests, OC slots ready, etc. Notifications go through a small companion page you install once per device.

Set up (mobile browser — iPhone Safari 16.4+ or Android Chrome)

  1. Open tornwar.com/notifications in Safari (iPhone) or Chrome (Android). Don't use Torn PDA's in-app browser — Web Push doesn't work there.
  2. Add to Home Screen — this is required on iPhone for Web Push to work:
    • iPhone Safari: tap the Share button → Add to Home Screen → Add
    • Android Chrome: tap the menu (⋮) → Add to Home screen / Install app
  3. Open the new "OC Notif" icon from your home screen.
  4. Paste your Torn API key (same one you used in FactionOps), tap Login.
  5. Tap Enable Notifications — your phone will ask permission, tap Allow.
  6. Toggle which alert types you want (vault requests, chain alerts, OC ready, etc.). Defaults are sensible.
  7. Tap Send Test Notification to confirm it works. You should get a test push within a few seconds.

Set up (desktop — Chrome / Edge / Firefox)

  1. Open tornwar.com/notifications.
  2. Paste your API key, tap Login.
  3. Tap Enable Notifications, click Allow when the browser asks for permission.
  4. Toggle the alert types you want, send a test notification to confirm.

Desktop notifications fire even when your browser is in the background. If you close all browser windows, they stop until you reopen one — for always-on alerts, install on mobile too.

Torn PDA users — read this

The Torn PDA app's in-app browser can't receive Web Push directly (it's a known Flutter limitation). Two workarounds:

  1. Recommended: set up notifications on a separate device — iPhone Safari (with Add to Home Screen) or Android Chrome — using the steps above. PDA stays as your gameplay app; the other device receives the alerts.
  2. If you use Android, you can do this on the same phone: install the notifications PWA in Chrome, separately from PDA. Both apps then run side-by-side — PDA for play, PWA for alerts.

8Native apps (optional)

Don't want to keep a browser tab open all the time? FactionOps has native apps for iOS and Android. They bundle the war overlay and push notifications in one install — no Tampermonkey, no PWA juggling, no "what device am I on" question.

Android

  1. On your Android phone, download tornwar.com/warboard.apk.
  2. Tap the downloaded file. Android will warn you it's from an unknown source — tap Settings → enable Allow from this source for your browser → back → Install.
  3. Open the app, paste your Torn API key (same one as the script), tap Sign in.
  4. Grant notification permission when prompted.

The app auto-updates from the same URL. If you ever need to reinstall, the link is the same.

iOS

Distributed via Apple TestFlight (Apple's beta channel — same install flow as any TestFlight app).

  1. Install Apple's TestFlight app from the App Store if you don't already have it.
  2. Message RussianRob [137558] in Torn with the email address tied to your Apple ID and ask for a TestFlight invite.
  3. You'll get an email invite — tap View in TestFlight → Accept → Install.
  4. Open the app, paste your Torn API key, sign in. Grant notification permission.

iOS app extras: Live Activity (lock-screen chain timer) and Dynamic Island support on iPhone 14 Pro+ models.

What about Mac / Desktop?

There's no separate desktop app needed — the userscript + browser is the desktop experience. If you want background push on a Mac without a browser open, install the iOS app on your iPhone (it's always on you anyway).

Quick decision guide
  • Android phone: install the APK above. Done.
  • iPhone: get the TestFlight invite. Best in-game experience for iOS.
  • Desktop only: userscript + Section 7 PWA notifications cover you.
  • Torn PDA user: keep PDA for play; add the native app (or a separate-device PWA) for push.

9Help

  • Script not loading / overlay missing: refresh the page once. If still nothing, check Tampermonkey is enabled for torn.com in your browser's extensions menu.
  • Got logged out / "invalid API key" error: click the ⚙ gear in the FactionOps overlay → re-paste your API key → Save → refresh.
  • Wrong faction shown / blank data: verify the API key in the gear menu belongs to the right Torn account.
  • Anything else: message faction leadership in-game.
