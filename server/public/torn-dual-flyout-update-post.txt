<h2>Torn Dual Flyout: pinned links</h2>
<p><em>A row under the header for the links you use most</em></p>
</div>

<p>Someone wanted pinned links in the top bar, so I added them.</p>

<ul>
<li>Tap the gear next to the menu button and tick the links you want. They show in a row under the header.</li>
<li>Pinned links come out of the menu, and the menu button stops counting them.</li>
<li>To reorder, hold a link in the Bar order list and drag it.</li>
<li>The row wraps to a second line instead of sliding.</li>
<li>Your settings carry over. No API key needed.</li>
</ul>
